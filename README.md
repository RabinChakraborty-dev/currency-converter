# 💱 Currency Converter

A simple and user-friendly Currency Converter web application built using **HTML, CSS, and JavaScript**. It allows users to convert an amount from one currency to another using the available exchange-rate data.

## ✨ Features

* 🌍 Convert between different currencies.
* 💰 Enter an amount to convert.
* 🚩 Display country flags for selected currencies.
* 🔄 Select the source and target currencies.
* 📱 Simple and user-friendly interface.
* ⚡ Instant conversion based on the exchange-rate data used by the application.

## 🛠️ Technologies Used

* **HTML5** — Structure of the application.
* **CSS3** — Styling and responsive layout.
* **JavaScript** — Currency selection and conversion logic.

## 🚀 How to Run Locally

1. Clone this repository:

   ```bash
   git clone https://github.com/RabinChakraborty-dev/currency-converter.git
   ```

2. Open the project folder:

   ```bash
   cd currency-converter
   ```

3. Open `index.html` in your web browser.

   You can also open the project folder in VS Code and use the Live Server extension.
